```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int preSum = 0;
        // 前缀和 -> 索引+1
        Map<Integer, Integer> preSumIndex = new HashMap<>();
        preSumIndex.put(0, 0);
        for (int i =0; i<nums.length; i++) {
            preSum += nums[i];
            if (preSum > x) {
                break;
            }
            preSumIndex.put(preSum, i + 1);
        }
        int ans = Integer.MAX_VALUE;
        if (preSumIndex.containsKey(x)) {
            ans = preSumIndex.get(x);
        }
        int suffixSum = 0;
        for (int i = nums.length -1; i>=0; i--) {
            suffixSum += nums[i];
            if (suffixSum > x) {
                break;
            }
            // 前缀和中是否有x - suffixSum
            Integer pre = preSumIndex.get(x - suffixSum);
            if (pre != null) {
                int op = pre + nums.length - i;
                // 判断是否超过数组长度,即 前缀和 后缀和 重叠了
                if (op <= nums.length) {
                    ans = Math.min(ans, op);
                }
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

因为后缀和是递增的, 找指定的前缀和肯定是往左的, 所以让ai帮忙优化了一下
```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int n = nums.length;
        // preSum[i] 前缀和 [0,i)
        int[] preSum = new int[n + 1];
        for (int i = 0; i < n; i++) {
            preSum[i + 1] = preSum[i] + nums[i];
        }
        int ans = Integer.MAX_VALUE;
        int j = n;
        int suffixSum = 0;
        // i == n means an empty suffix, i.e. removing from the left only
        for (int i = n; i >= 0; i--) {
            if (i < n) {
                suffixSum += nums[i];
                if (suffixSum > x) {
                    break;
                }
            }
            // suffixSum 是递增的, 因此前缀和的指针 j 总是往左
            while (j >= 0 && preSum[j] > x - suffixSum) {
                j--;
            }
            // 前缀和中是否有x - suffixSum
            if (j >= 0 && preSum[j] == x - suffixSum) {
                int op = j + n - i;
                // 判断是否超过数组长度,即 前缀和 后缀和 重叠了
                if (op <= n) {
                    ans = Math.min(ans, op);
                }
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

官解是通过滑动数组找最长的 sum - x 子数组
```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int n = nums.length;
        int sum = Arrays.stream(nums).sum();

        if (sum < x) {
            return -1;
        }

        int right = 0;
        int lsum = 0, rsum = sum;
        int ans = n + 1;

        for (int left = -1; left < n; ++left) {
            if (left != -1) {
                lsum += nums[left];
            }
            while (right < n && lsum + rsum > x) {
                rsum -= nums[right];
                ++right;
            }
            if (lsum + rsum == x) {
                ans = Math.min(ans, (left + 1) + (n - right));
            }
        }

        return ans > n ? -1 : ans;
    }
}
```
