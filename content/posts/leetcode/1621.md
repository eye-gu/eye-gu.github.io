在65个用例上超时了, n=1000, k=500. 时间复杂度是 n*k*k
```java
    class Solution {
        public int numberOfSets(int n, int k) {
            int mod = 1000000007;
            // dp[i][j] 表示前i个点，有j个线段的方案数
            int[][] dp = new int[n + 1][k + 1];
            for (int i = 1; i <= n; i++) {
                // 有0个线段的方案数都是1
                dp[i][0] = 1;
                for (int j = 1; j <= k; j++) {
                    // i点不选, 那么就和i-1数量一样
                    dp[i][j] = dp[i-1][j];
                    // i点作为最后一个线段的右端点, 左端点可以是前i-1的任意点
                    for (int m = 0; m < i; m++) {
                        dp[i][j] = (dp[i][j] + dp[m][j - 1]) % mod;
                    }
                }
            }
            return dp[n][k];
        }
    }
```

===================== 推导: 消掉内层 m 循环, O(n^2*k) -> O(n*k) =====================
v1 递推: dp[i][j] = dp[i-1][j] + Σ(m=1..i-1) dp[m][j-1]
求和项是 j-1 列的前缀和。对 i-1 行写出同样的方程:
    dp[i-1][j] = dp[i-2][j] + Σ(m=1..i-2) dp[m][j-1]
做差得: Σ(m=1..i-2) dp[m][j-1] = dp[i-1][j] - dp[i-2][j]
代回 v1:
    dp[i][j] = dp[i-1][j] + (dp[i-1][j] - dp[i-2][j]) + dp[i-1][j-1]
             = 2*dp[i-1][j] - dp[i-2][j] + dp[i-1][j-1]
前缀和只是推导脚手架, 消元后 dp 自己满足该递推, 无需额外的前缀和表
(更进一步: 闭式解 dp[n][k] = C(n+k-1, 2k), 配合费马小定理求逆元可 O(k+log p))

```java
    class Solution {
        public int numberOfSets(int n, int k) {
            int mod = 1000000007;
            // dp[i][j] = 前 i 个点恰好放 j 条线段的方案数 (对 mod 取余)
            int[][] dp = new int[n + 1][k + 1];
            // 边界: 0 条线段方案恒为 1; dp[0][*] 与 dp[1][j>=1] 保持默认值 0
            dp[1][0] = 1;
            for (int i = 2; i <= n; i++) {
                dp[i][0] = 1;
                for (int j = 1; j <= k; j++) {
                    // 按语义分三组:
                    // dp[i-1][j]               点 i-1 不当右端点
                    // dp[i-1][j] - dp[i-2][j]  Σ(m=1..i-2) dp[m][j-1] 的差分形式
                    // dp[i-1][j-1]             前缀和最后一项 m=i-1, 即线段 [i-2, i-1]
                    // (long) 提升: 上界约 3*mod 超出 int; 取模回绕后相减可能为负, 需 +mod 兜底
                    long tmp = (long) dp[i-1][j] - dp[i-2][j] + dp[i-1][j-1] + dp[i-1][j];
                    dp[i][j] = (int) ((tmp % mod + mod) % mod);
                }
            }
            return dp[n][k];
        }
    }
```
