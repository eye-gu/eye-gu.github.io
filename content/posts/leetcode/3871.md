```java
    class Solution {
        public long countCommas(long n) {
            if (n < 1000) {
                return 0;
            }
            return help(n, 1000, 1);
        }

        // 1000-999999 每个是1个
        // 1000000-999999999 每个是2个
        // base: 1000 1000000 1000000000
        private long help(long n, long base, int multi) {
            long nextBase = base * 1000;
            if (n < nextBase) {
                return (n - base + 1) * multi;
            }
            return (nextBase - base) * multi + help(n, nextBase, multi + 1);
        }
    }
```

官解
```java
    // 大于等于 1000的数，都会包含至少 1 个逗号，这一部分总共贡献 n−1000+1 个逗号。
    //大于等于 1000000的数，会包含至少 2 个逗号（即在前一步的基础上，每个数额外多贡献 1 个逗号），总共额外贡献 n−1000000+1个逗号
    class Solution {
        public long countCommas(long n) {
            long p = 1000, res = 0;
            while (p <= n) {
                res += n - p + 1;
                p *= 1000;
            }
            return res;
        }
    }
```
