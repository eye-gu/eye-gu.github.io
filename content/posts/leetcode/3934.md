一开始使用了字符串拼接做的hash，超时了
```java
    class Solution {
        public int smallestUniqueSubarray(int[] nums) {
            int min = 1;
            int max = nums.length;
            while (min < max) {
                int mid = (max - min) / 2 + min;
                if (check(nums, mid)) {
                    max = mid;
                } else {
                    min = mid+1;
                }
            }
            return max;
        }

        private boolean check(int[] nums, int len) {
            Map<String, Integer> cache = new HashMap<>();
            for (int i =0; i<=nums.length - len; i++) {
                StringBuilder sb = new StringBuilder();
                for (int j=i; j<i+len; j++) {
                    sb.append(nums[j]).append(' ');
                }
                String hash = sb.toString();
                if (cache.containsKey(hash)) {
                    cache.put(hash, cache.get(hash) + 1);
                } else {
                    cache.put(hash, 1);
                }
            }
            return cache.values().stream().anyMatch(count -> count == 1);
        }
    }
```

经ai大人的提示，使用了滚动hash。核心是把子数组看成base进制的数，每次向右滚动，把最左边的数去掉（去掉时要乘以base的len-1次方，即提前算好的pow），乘以base，把最右边的数加进来。
```java
    class Solution {
        public int smallestUniqueSubarray(int[] nums) {
            int min = 1;
            int max = nums.length;
            while (min < max) {
                int mid = (max - min) / 2 + min;
                if (check(nums, mid)) {
                    max = mid;
                } else {
                    min = mid+1;
                }
            }
            return max;
        }

        private boolean check(int[] nums, int len) {
            int n = nums.length;
            long base = 1000003L;
            long pow = 1;
            for (int i = 1; i < len; i++) {
                pow *= base;
            }
            long hash = 0;
            for (int i = 0; i < len; i++) {
                hash = hash * base + nums[i];
            }
            Map<Long, Integer> count = new HashMap<>();
            count.merge(hash, 1, Integer::sum);
            for (int i = len; i < n; i++) {
                hash = (hash - nums[i - len] * pow) * base + nums[i];
                count.merge(hash, 1, Integer::sum);
            }
            return count.containsValue(1);
        }
    }
```
