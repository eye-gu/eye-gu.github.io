只考虑了相交重叠, 没有考虑完全重叠, 和十字相交重叠, 这两种情况
```java
    class Solution {
        public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
            int[] rightUp = new int[]{rec1[2], rec1[3]};
            int[] leftDown = new int[]{rec1[0], rec1[1]};
            int[] rightDown = new int[]{rec1[2], rec1[1]};
            int[] leftUp = new int[]{rec1[0], rec1[3]};

            if (rightDown[0] > rec2[0] && rightDown[0] < rec2[2] && rightDown[1] > rec2[1] && rightDown[1] < rec2[3]) {
                return true;
            }
            if (leftUp[0] > rec2[0] && leftUp[0] < rec2[2] && leftUp[1] > rec2[1] && leftUp[1] < rec2[3]) {
                return true;
            }
            if (leftDown[0] > rec2[0] && leftDown[0] < rec2[2] && leftDown[1] > rec2[1] && leftDown[1] < rec2[3]) {
                return true;
            }
            if (rightUp[0] > rec2[0] && rightUp[0] < rec2[2] && rightUp[1] > rec2[1] && rightUp[1] < rec2[3]) {
                return true;
            }
            return false;
        }
    }
```


把点投影到x轴和y轴, 只要两轴的投影都是相交的, 那么两个矩形就是相交的
```java
    class Solution {
        public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
            return rec1[0] < rec2[2] && rec2[0] < rec1[2] // x轴相交
                    && rec1[1] < rec2[3] && rec2[1] < rec1[3]; // y轴相交
        }
    }
```
