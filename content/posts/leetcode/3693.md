```java
    class Solution {
        public int climbStairs(int n, int[] costs) {
            // dp[i] 代表到达第i阶台阶的最小成本
            int[] dp = new int[n + 1];
            for (int i=1; i<=n; i++) {
                dp[i] = dp[i-1] + costs[i-1] + 1;
                if (i >= 2) {
                    dp[i] = Math.min(dp[i], dp[i-2] + costs[i-1] + 4);
                }
                if (i >= 3) {
                    dp[i] = Math.min(dp[i], dp[i-3] + costs[i-1] + 9);
                }
            }
            return dp[n];
        }
    }
```

因为最大只能跨三个台阶，因为可以空间优化

```java
    class Solution {
        public int climbStairs(int n, int[] costs) {
            // 第一个台阶
            int a = 0;
            // 第二个台阶
            int b = 0;
            // 第三个台阶
            int c = 0;
            for (int i = 0; i < n; i++) {
                int next = Math.min(Math.min(a + 1, b + 4), c + 9) + costs[i];
                c = b;
                b = a;
                a = next;
            }
            return a;
        }
    }
```
