一开始以为赠品最多一个，用了贪心，每次购买单价最便宜的商品
既然第一次购买，赠品是所有整除的商品，那么就不能使用贪心，因为单价最便宜的商品，数量可能很少，买了后剩余的钱又不够继续买了，反而不是最优解。

```java
    class Solution {
        public int maximumSaleItems(int[][] items, int budget) {
            int n = items.length;
            int[] gifts = new int[n];
            for (int i =0; i<n; i++) {
                for (int[] item : items) {
                    if (item[0] % items[i][0] == 0) {
                        gifts[i]++;
                    }
                }
            }

            int minPrice = items[0][1];
            // dp[b] 代表花b块钱，最大可以获得的数量
            int[] dp = new int[budget + 1];
            for (int i =0; i<n; i++) {
                int price = items[i][1];
                int count = gifts[i];

                minPrice = Math.min(minPrice, price);

                // 从budget开始递减，从小往大，大的就重复算了
                for (int b = budget; b >= price; b--) {
                    dp[b] = Math.max(dp[b], dp[b - price] + count);
                }
            }

            // 买最小价格，不赠送的情况。这里必须要从小到大，因为大的代表钱花的多，可以买多个最小价格的商品
            for (int b = minPrice; b <= budget; b++) {
                dp[b] = Math.max(dp[b], dp[b - minPrice] + 1);
            }
            return dp[budget];
        }
    }
```
