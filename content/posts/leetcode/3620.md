https://leetcode.cn/problems/network-recovery-pathways/description/?envType=daily-question&envId=2026-07-03



自己写的Dijkstra, 但是因为有最小权重和权重和两个条件,不能充分剪枝,因此会超时

```java
class Solution {
        public int findMaxPathScore(int[][] edges, boolean[] online, long k) {
            int n = online.length;
            List<int[]>[] graph = new List[n];
            for (int i = 0; i < n; i++) {
                graph[i] = new ArrayList<>();
            }
            for (int[] edge : edges) {
                graph[edge[0]].add(new int[]{edge[1], edge[2]});
            }

            // 存放每个节点最大的 最小权重
            int[] nodeMaxMin = new int[n];
            Arrays.fill(nodeMaxMin, -1);
            // 存放每个节点最小的路径权重和
            int[] nodeMinSum = new int[n];
            Arrays.fill(nodeMinSum, Integer.MAX_VALUE);
            // 节点id,路径最小权重,路径权重和
            // Dijkstra 每次取当前最大的 最小权重的路径
            PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[1] - a[1]);
            pq.offer(new int[]{0, Integer.MAX_VALUE, 0});
            while (!pq.isEmpty()) {
                int[] poll = pq.poll();
                int node = poll[0];
                int minWeight = poll[1];
                int sumWeight = poll[2];
                if (node == n - 1) {
                    // 因为是优先级队列,每次取当前最大的 最小权重的路径,因此到达n-1就可以提前退出
                    return minWeight;
                }
                for (int[] edge : graph[node]) {
                    int next = edge[0];
                    int weight = edge[1];
                    int nextMin = Math.min(minWeight, weight);
                    int nextSum = sumWeight + weight;
                    if (!online[next]) {
                        continue;
                    }
                    if (nextSum > k) {
                        continue;
                    }
                    // 只能剪枝掉,最小权重更小,且路径权重和更大的, 因此时间复杂度高,会超时
                    if (nodeMaxMin[next] >= nextMin && nodeMinSum[next] <= nextSum) {
                        continue;
                    }
                    nodeMaxMin[next] = Math.max(nodeMaxMin[next], nextMin);
                    nodeMinSum[next] = Math.min(nodeMinSum[next], nextSum);
                    pq.offer(new int[]{next, nextMin, sumWeight + weight});
                }
            }
            return -1;
        }
    }
```
