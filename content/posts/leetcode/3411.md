根据ai的提示，因为nums中的数小于等于10，所以product不会超过25200
```java
    class Solution {
        public int maxLength(int[] nums) {
            int res = 1;
            for (int i =0; i<nums.length; i++) {
                int prod = nums[i];
                int lcm = nums[i];
                int gcd = nums[i];
                for (int j =i+1; j<nums.length; j++) {
                    prod = prod * nums[j];
                    if (prod > 25200) {
                        break;
                    }
                    lcm = lcm(lcm, nums[j]);
                    gcd = gcd(gcd, nums[j]);
                    if (lcm * gcd == prod) {
                        res = Math.max(res, j - i + 1);
                    }
                }
            }
            return res;
        }

        private int lcm(int a, int b) {
            return a / gcd(a, b) * b;
        }

        private int gcd(int a, int b) {
            if (b == 0) {
                return a;
            }
            return gcd(b, a%b);
        }
    }
```


看了官解的第一个思路，prod > gcd * lcm break，因为新加一个数n，prod会变大n倍，gcd * lcm变大最大也是n倍，因此这个大于关系不可逆
```java
class Solution {
    public int maxLength(int[] nums) {
        int res = 0;
        for (int i = 0; i < nums.length; i++) {
            long prodVal = nums[i];
            long gcdVal = nums[i];
            long lcmVal = nums[i];
            for (int j = i + 1; j < nums.length; j++) {
                prodVal = prodVal * nums[j];
                gcdVal = gcd(gcdVal, nums[j]);
                lcmVal = lcmVal * nums[j] / gcd(lcmVal, nums[j]);
                if (prodVal > gcdVal * lcmVal) {
                    break;
                }
                if (prodVal == gcdVal * lcmVal) {
                    res = Math.max(res, j - i + 1);
                }
            }
        }
        return res;
    }
    
    private long gcd(long a, long b) {
        while (b != 0) {
            long temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
}
```


官解的第二个思路，滑动窗口，gcd(prod, nums[end]) > 1，说明prod和nums[end]不互质，此时无法将nums[end]加入现在的窗口，因此需要将prod除以nums[start]，start++，直到gcd(prod, nums[end]) == 1，此时可以将nums[end]加入窗口
```java
    class Solution {
        public int maxLength(int[] nums) {
            int res = 2;
            int prodVal = 1;
            int n = nums.length;
            int start = 0, end = 0;

            while (end < n) {
                while (gcd(prodVal, nums[end]) > 1) {
                    prodVal /= nums[start];
                    start++;
                }
                prodVal *= nums[end];
                res = Math.max(res, end - start + 1);
                end++;
            }
            return res;
        }

        private int gcd(int num1, int num2) {
            while (num2 != 0) {
                int temp = num1;
                num1 = num2;
                num2 = temp % num2;
            }
            return num1;
        }
    }
```
